# Conway's Game of Life - Laboratorio 2

Implementación del **Juego de la Vida de Conway** utilizando **Zig** y **Raylib**, desarrollada como parte del Laboratorio 2 del curso de Gráficas por Computadora.

</p>


## Requisitos

- Zig 0.16.0
- Raylib

## Compilar y ejecutar

Clonar el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
cd conways_game_of_life_lab2
```

Ejecutar:

```bash
zig build run
```
